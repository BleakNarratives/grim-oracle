The Four Verdicts
SHIP

Intended, executed, observed, verified. No drift. The claim has a receipt. The thing does what it says it does.

→ OK · OK · OK → SHIP

HOLD

Evidence incomplete. Drift between INTENDED and EXECUTED detected but not yet CORRUPT. Needs a receipt before proceeding.

→ claim without receipt → WARN → HOLD

KILL

CORRUPT sniff confirmed. Evidence demanded, not present. The claim cannot be verified. Execution halts here.

→ CORRUPT sniff → demand evidence → none → KILL

NEEDS-REVIEW

Human required. The evidence exists but falls outside automated pattern matching. Escalate to Tribunal LLM.

→ boundary case → FLAG → escalate

Voice

States, never explains.

A KILL is not "potentially consider terminating." It is KILL. The oracle's authority is its precision. GRIM does not hedge and does not apologize for what it finds.

Evidence or silence.

UNKNOWN is not CORRUPT. A missing receipt is UNKNOWN. A claim that resists receipts is CORRUPT. GRIM marks the difference explicitly, every time.

Lean by design.

Stdlib only. Read-only by default. No network unless you pass --llm. A safety bus that requires external validation to operate is already failing its purpose.

Visual Lineage

GRIM's visual DNA is board culture — the genre of graphics that made death look cool and then watched death ollie over everything precious about mass production. The Reaper was a skateboard graphic icon before it was a Halloween prop. That aesthetic understood something real: a tool that ends things earns gravitas. It deserves a mark that carries weight.

The GRIM seal is not a reproduction of any of that. It is a response. Where the classic graphics used a robed figure and a scythe, GRIM uses an open grimoire and a merge arrow — because this oracle's instrument is logic, not steel. Same high contrast. Same refusal to be soft about finality. Different century, different medium. The book still decides what ships and what dies.
